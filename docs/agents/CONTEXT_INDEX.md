# Context lookup

Read this index, then only the note relevant to the task. Search recent
`*-log.md` headings for newer handoffs. These notes preserve context, not
authority to start work or a guarantee of current runtime state.

- **Branch, environment, uncommitted work:** [workspace](context/workspace.md).
  Read before implementing; use [architecture](../ARCHITECTURE.md) for paths.
- **Provider, data windows, maps, comparison:**
  [data and maps](context/data-and-maps.md). Read for product/data decisions.
- **Completed agent setup:** [coordination history](context/coordination-history.md).
  Read only when changing the team workflow or investigating old assignments.
- **Completed code rounds and verification:** [completed rounds](context/completed-rounds.md).
  Look up task IDs/merge revisions instead of loading old assignment transcripts.
- **What was cleaned, cache recovery, retained files:**
  [maintenance](context/maintenance.md). Read before further cleanup.

The Lead maintains this index; coordinate ownership before changing a topic
note. Keep each note short, dated, and linked to its source. Update or merge
existing topics before adding files. Preserve unresolved decisions; remove
obsolete notes and their index links together. Do not load the whole folder
at startup or copy source documents into it.
