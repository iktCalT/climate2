NOAA source, licence, and data limitations

Keep a smaller climate cache

Keep 1950–1954 and 2022–2026. Cleanup permanently removes climate rows outside those years from every provider, including the active Open-Meteo cache. Accounts, profiles, and location definitions are not changed.

Back up the database first for exact recovery. Re-fetching may produce revised values. Pause command-line imports before cleanup. Public browsing does not refill removed rows; explicit import tools still can. This is not an automatic retention rule.

Smaller storage does not guarantee faster queries. Database files may not shrink immediately; normal PostgreSQL maintenance reuses freed space. No disruptive full-database compaction runs here.
