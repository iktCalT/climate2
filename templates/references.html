Climate sources and limitations

API documentation Open-Meteo Climate API

Daily, downscaled climate-model variables used for temperature and precipitation.

open-meteo.com ↗ Dataset terms CMIP6 Terms of Use

Licensing and acknowledgement requirements for the underlying CMIP6 model data.

pcmdi.llnl.gov ↗ Selected bulk source · inactive on site NOAA Conventional Observation Reanalysis (CORe)

Official global reanalysis from 1950 to near real time, available anonymously and documented as public domain.

cpc.ncep.noaa.gov ↗ Public data archive NOAA CORe NODD archive

Anonymous HTTPS access to monthly, daily, and 3-hourly CORe files without an account or API key.

cpc.ncep.noaa.gov ↗ Field documentation NOAA CORe retrieval guide

Monthly, daily, and 3-hourly file layout, indexed record selection, variable definitions, timing semantics, and public-domain notice. The importer uses the documented 3-hourly 0–3 hour extrema only when both daily extrema are absent.

ftp.cpc.ncep.noaa.gov ↗ Data policy NOAA NCEI open-data policy

NOAA policy for public-domain data in the United States and CC0 dedication where rights may otherwise exist.

ncei.noaa.gov ↗ Grid documentation NOAA CORe regridding guidance

Documents the native 512-by-256 Gaussian grid and supported approaches for conversion to a regular grid.

cpc.ncep.noaa.gov ↗ Technical overview NOAA Physical Sciences Laboratory CORe overview

Explains CORe's reanalysis role, atmospheric representation, and operational file family.

psl.noaa.gov ↗ Operational announcement NOAA Weather Program Office CORe announcement

Records NOAA's operational transition to CORe for climate monitoring.

wpo.noaa.gov ↗ Evaluated predecessor NCEP/NCAR Reanalysis 1 update notice

Explains the end of operational updates, which is why the retired predecessor was not selected.

psl.noaa.gov ↗ Evaluated alternative Copernicus CDS ERA5 monthly data

Authoritative global source not selected because API use requires an account, licence acceptance, and token.

cds.climate.copernicus.eu ↗ Evaluated source NASA POWER monthly API

Safe documented global source evaluated but not selected because meteorological coverage starts in 1981.

power.larc.nasa.gov ↗ Evaluated source CRU gridded datasets

Historical land-only climate data evaluated but not selected as the global active provider.

crudata.uea.ac.uk ↗
Open-Meteo states that past and recent values from this Climate API are model output used for validation—not direct measurements. Results should be treated as modelled climate information.
Provider research selected NOAA CORe as the bulk import source. It is global from 1950 to near real time, available through anonymous HTTPS, and documented by NOAA as public domain. It is a reanalysis rather than the site's current CMIP6 model output, and its convenient monthly high/low fields are averages of daily extrema. The importer therefore derives monthly extremes from daily CORe records, validates every field with ECMWF ecCodes, and writes a separate noaa_core family. When both daily extrema are absent, it requires all eight exact 0–3 hour extrema pairs from the documented 3-hourly archive and rejects incomplete evidence. May 2026 live validation exercised this path for May 19. The local PostgreSQL checkpoint now contains all 92 requested months across 1950–1953 and 2023–2026, each with 8,281 canonical rows and all four metrics. A separate opt-in period can resume bounded, month-atomic backfill from January 1950 through the latest complete month; it does not change the active website provider. Its first eight live batches added all months of 1954–1961, bringing the implementation checkpoint to 188 of 920 complete months, with 1962 next. A read-only PostgreSQL report also compared all 8,281 canonical rows for January 1950, leap-month February 1952, and July 2023. Six bounded Open-Meteo requests also completed the required August 2026 land, ocean, polar, and dateline samples without attempting a global refill. Expected differences were material for precipitation and temperature extrema, so they are review evidence rather than automatic pass/fail thresholds. Open-Meteo and open_meteo_cmip6 remain active pending full-history coverage and a separate provider decision; the site does not silently mix the reanalysis and two-model CMIP6 products. The shared footer follows that active-provider setting: it credits Open-Meteo and CMIP6 now and will display NOAA CORe only after an explicit activation switches live reads to noaa_core.

This fork: an AI-assisted refactor produced with OpenAI Codex (GPT-5), under the human owner’s direction and review.

Project icon: sourced from Iconfinder.

Attribution policy: every external resource must be cited in both this page and the repository README in the same change that introduces it.

Repository privacy: secrets, credentials, private keys, populated databases, session data, personal information, and machine-specific configuration must never be committed or pushed. Sensitive values stay in ignored local configuration or environment variables, and staged changes are checked before publication.
