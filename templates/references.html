Climate sources and limitations

Active public source

{% if climate_provider == "noaa_core" %}

Maps and Locations read saved noaa_core data from NOAA CORe reanalysis. These are gridded estimates informed by observations, not direct station observations at a requested point. Maps show a smooth bilinearly interpolated estimate from the 2° × 4° source grid; this adds no source resolution or accuracy, and missing source nodes remain unavailable. Map clicks use the same numeric interpolation as the raster. Location history samples one fixed 2° × 4° grid coordinate throughout the series and shows its distance from the request. Temperatures are in °C; precipitation is mean daily mm/day, not a monthly total.

{% else %}

Maps and Locations read saved open_meteo_cmip6 data from Open-Meteo's downscaled CMIP6 climate models. These are model outputs, not direct station observations or observed weather for a particular date. Temperatures are in °C; precipitation is mean daily mm/day, not a monthly total.

{% endif %}

Coverage is uneven

Visitors do not trigger provider downloads or queue missing values. Map dates can be selected from January 1950 through the current month; Location history starts in January 1951. A selectable date does not guarantee saved values for a region, coordinate, or variable. Maps opens the newest saved mean-temperature month within its stable-date limit unless you choose a date. Saved-month counts come from bounded, read-only cache queries and count finite active-provider values globally, not regional completeness or accuracy.

Separate source

{% if climate_provider == "noaa_core" %}

Open-Meteo CMIP6 model output remains stored separately as open_meteo_cmip6 and is inactive for public Maps and Locations. Reanalysis and CMIP6 model output have different provenance and are not silently mixed.

{% else %}

NOAA CORe is a selected, administrator-managed reanalysis import source stored as noaa_core. It is inactive for public Maps and Locations. Reanalysis and CMIP6 model output have different provenance and are not silently mixed.

{% endif %}

Reading a comparison

On Maps, select one variable and two to four months. Click a location in any panel to see each month's own value and provenance at the same coordinates. NOAA values are interpolated estimates from source-grid values; CMIP6 readouts retain their containing-cell value. The first month is the labelled baseline; later panels show signed differences in °C or mm/day when both values are available. The displayed difference uses at most two decimal places, but is calculated from unrounded values. If either value is an estimate, the difference is labelled estimate-based. These differences are not exact-location observations or a climate trend. Loading, failed and missing data explain why a difference is unavailable. Valid selected coordinates link to saved Location history, which uses its own sampling rule and may differ from a map display estimate. Single-map readouts have no baseline or difference. All panels share a manual color scale. Choose a preset or custom range to keep colors comparable; narrower color bands do not improve data accuracy.

NOAA CORe is a global, near-real-time reanalysis available through anonymous HTTPS and documented by NOAA as public domain. Its convenient monthly high/low fields average daily extrema, so the importer derives monthly extremes from daily records and validates fields with ECMWF ecCodes. Only when both daily extrema are absent does it require all eight exact 0–3 hour extrema pairs from the documented 3-hourly archive; incomplete evidence is rejected. May 2026 validation exercised that path for May 19.

Earlier checkpoint reports recorded 92 requested months across 1950–1953 and 2023–2026 with 8,281 canonical rows and four metrics per month. Later bounded backfills reported 248 of 920 complete months after 1954–1966, then 284 of 920 after 2020–2022, including 80 of 128 recent-window months. Those are dated progress records, not a claim about today's database. Routine administrator acquisition was subsequently narrowed to the first and last five years, 1950–1954 and 2022–2026, through the latest complete month. Older saved rows remain unless explicitly removed.

Read-only PostgreSQL comparisons covered all 8,281 canonical rows for January 1950, leap-month February 1952, and July 2023. Six bounded Open-Meteo requests sampled August 2026 land, ocean, polar, and dateline cases. Material differences in precipitation and temperature extrema are review evidence, not automatic pass/fail thresholds or approval to switch the public provider. Location chart URLs reflect current data on a new page request; seasonal averages use available months and may be incomplete. Old generated chart files are not automatically deleted.

This fork: an AI-assisted refactor produced with OpenAI Codex (GPT-5), under the human owner’s direction and review.

Attribution policy: every external resource must be cited in both this page and the repository README in the same change that introduces it.

Repository privacy: secrets, credentials, private keys, populated databases, session data, personal information, and machine-specific configuration must never be committed or pushed. Sensitive values stay in ignored local configuration or environment variables, and staged changes are checked before publication.
