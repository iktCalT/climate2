How comparisons and location history work

On Maps, choose two to four months and a variable. Click a location to see each month's value and source; later months show signed differences from the first when both values exist.

{% if climate_provider == "noaa_core" %}

NOAA map readouts are interpolated estimates from the saved 2° × 4° grid. Locations rounds latitude and longitude separately to one fixed grid point and reports its distance from your request.

{% else %}

CMIP6 map readouts use the saved containing-cell value; Locations looks up saved history at the requested coordinates.

{% endif %}

Maps share a manual color scale that stays fixed until you change it. Narrower ranges show more contrast, not more accuracy.
